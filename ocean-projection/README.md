# Ocean · 小组整合投影版

唯一运行入口：`index.html`。请保留整个文件夹，不要只复制 main.js。

## 第一次运行

1. 解压压缩包，在 VS Code 中打开解压后的 `ocean-projection` 文件夹。
2. 右键 `index.html` → Open with Live Server。也可以在此文件夹运行 `python -m http.server 8000`，再打开 `http://localhost:8000`。
3. 等左上角显示“已加载 10 个投影区域”。首次显示的是平铺预览，方便确认所有作品都能出现，并不是最终装置摆放图。
4. 接好投影仪，固定投影仪与所有物体的位置；把浏览器窗口移到投影屏幕，先按 F 全屏。
5. 在“显示”下拉菜单中选择一个投影面，按 T 显示定位测试图，按 C 开启校准。
6. 普通矩形面：拖动四角贴合物体边界，拖动面内部移动整体。伞面：拖动十个边缘点。Hanni B+C：拖动上排三个点、下排三个点；中间两点由两个侧面共用。
7. 每个面调好后选择下一个。最后选择“全部投影面”，关闭测试图、关闭校准，按 H 隐藏面板。
8. 按 S 下载 `ocean-projection-map.json`。这一份文件保存了全部位置，包括 B+C 的六个点。请保留备份。
9. 下次用相同投影位置与分辨率打开后，按 L 选择这份 JSON 即可。浏览器也会缓存当前布局，但迁移电脑时请以下载的 JSON 为准。

黑色区域不会主动投射亮图案；实际黑位仍受投影仪与现场环境影响。

## 按键

| 按键 | 功能 |
| --- | --- |
| F | 全屏/退出全屏 |
| C | 开关校准网格和控制点 |
| T | 作品/定位测试图 |
| H | 隐藏/显示左上角面板 |
| S | 保存全部校准为一个 JSON |
| L | 选择并加载整合版 JSON |
| Space | 暂停/继续全部动画 |
| 0 | 显示全部投影面 |
| 1–9 | 单独查看对应编号的投影面 |
| R | 经确认后，将位置重排成首次打开的平铺预览 |

编号 10 从下拉菜单选择。输入框或下拉菜单获得焦点时，部分快捷键会暂时让给该控件；点击画布即可继续操作。

## 文件结构与修改位置

| 文件/文件夹 | 用途 |
| --- | --- |
| index.html | 唯一打开的投影页面，加载全部依赖与场景 |
| main.js | 唯一的 setup/draw、投影面注册、布局、按键、统一校准保存/加载 |
| scenes/nora.js | Nora 的潮水与水母绘图 |
| scenes/hanni.js | Hanni 的图片路径、鱼群、珊瑚和垃圾运动 |
| scenes/yuki-fishbone.js | Yuki 的动态鱼骨 |
| scenes/yuki-ocean-color.js | Yuki 的彩色鱼群海面与瀑布 |
| scenes/yuki-ocean-white.js | Yuki 的白色鱼群海面与瀑布 |
| assets/hanni/ | Hanni 包中的全部 PNG，包括原参考图；运行时使用其中 13 张 |
| vendor/ | 从 Yuki 包中整理出的本地 p5.js 2.3.2 与 p5.mapper 副本 |
| originals/ | 整合前各份 JS 的备份，不会被页面加载 |
| maps/ | 可以存放下载的校准 JSON；按 L 可从任意位置选择文件 |

修改各自的作品时，编辑对应的 scenes 文件。不要把原来的完整 sketch.js 再直接加入 index.html；它们都有自己的 setup/draw，会相互覆盖。

整合时进行了这些调整：移除各场景重复的画布、mapper、键盘控制和 UI；把场景变量包在各自的作用域中；让它们返回自己的 createGraphics 纹理；统一由 main.js 投射。原图与主要绘图逻辑保留。

Yuki 包中的 `*.js.下载` 是网页另存为生成的文件名，现已整理为正常 JS；其中的 VS Code Live Preview 注入脚本、保存下来的 canvas HTML、重复库不参与新入口。

## 放进现有作品集

把整个 `ocean-projection` 文件夹放入 `Week8`，然后在 `Week8.html` 加：

```html
<a href="ocean-projection/index.html">Ocean — Group Projection</a>
```

无需新建 GitHub 仓库。先本地测试，确认后再把整份文件夹提交到已有仓库。

## 校准与测试说明

- 整合版更改了投影面的统一注册方式，因此旧项目中各自的 map.json 不应直接混用。第一次请重新校准，再保存整合版 JSON。
- 全屏、分辨率、投影仪或物体位置变化后，需要重新检查位置。页面不会在调整窗口时自动重排，以免覆盖手工校准。
- 带六点侧面的整合版 JSON 不是 p5.mapper 原生 map.json；请用本页面的 S/L 存取。
- 库、图片均为本地路径；运行不依赖 CDN，但仍需 Live Server 或其他 HTTP 服务器。
- 已做全部 JS 语法检查、资源路径检查，并用打包的 mapper 代码检查了初始化、两种鱼群切换、六点拖动和校准 JSON 往返。此环境没有完成真实浏览器 WebGL 与实体投影测试；清晰度、重叠和帧率需要现场确认。

整合素材/原场景：Nora、Hanni、Yuki。第三方库来源见 `vendor/README.txt`。
